# Research

One file per niche: `/docs/research/[niche].md`.

Each file records 20 portfolios. For each one: name, URL, layout, sections, visual style, and why it works. End each file with the required sections for that niche (used by the interview agent) and notes for the 20 original templates.

Scouted portfolios are inspiration for structure only. Never copy anyone's design, code, images or text.
