## Patterns

- **Hero:** name, role, one-line positioning, availability; actions: View Projects, Contact, CV.
- **Projects:** title, stack line, one-line summary, live link, repo link; best ones add "my part" and a measured result.
- **Two audiences:** employers (experience timeline, CV, GitHub) and clients (services, quote button, WhatsApp/phone).
- **Breadth routing:** multi-skilled creatives split work (Graphics / UI/UX / Code) into separate sections or pages.
- **Developer touches:** theme toggle, keyboard-friendly, command palette, fast load.

## Required sections for the interview agent (Web Development)

1. Identity: name, title (frontend, backend, full-stack, WordPress, Shopify), city, remote.
2. Audience: job seeker, freelancer/agency, or both.
3. Services (freelancers): websites, web apps, e-commerce, maintenance; optional starting prices.
4. Projects (3 to 8): name, what it does, your part, stack, live URL, repo, screenshot, result (only if given).
5. Stack and tools.
6. Experience timeline.
7. Open source, npm packages, writing (optional).
8. Contact: email, WhatsApp, phone, GitHub, LinkedIn, CV.
