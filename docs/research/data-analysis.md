**How this differs from Data Science.** Analysts sell business questions answered and dashboards people use. Interactive Power BI/Tableau embeds and clear recommendations matter more than models.

## Patterns

- Dashboard embeds (Power BI, Tableau Public, Looker Studio) with a screenshot fallback for slow networks.
- Each project: business question → data → cleaning → analysis → dashboard → recommendation.
- Labels for synthetic or anonymised data.
- Tools shown as filters (SQL, Excel, Power BI, Tableau, Python).
- Beginners: 3 to 5 complete projects beat 15 partial ones.

## Required sections for the interview agent (Data Analysis)

1. Identity: name, title, city, remote.
2. Tools: Excel, SQL, Power BI, Tableau, Looker, Python/R.
3. Projects (3 to 6): business question, dataset (source, real/synthetic), what you did, key insight, recommendation, dashboard link and screenshot, repo.
4. Domains: retail, finance, health, marketing, HR, logistics.
5. Experience, certifications (Google, Microsoft PL-300, etc.).
6. Contact: email, WhatsApp, LinkedIn, GitHub, Tableau Public/NovyPro.
