## Patterns (all data niches)

- **Result first:** one measured result per project on the card.
- **Case anatomy:** question → data (source, size, cleaning) → method and why → trade-offs/metric choice → result → caveats → links (demo, notebook, repo, dashboard).
- **Runnable proof:** live dashboard embeds, Streamlit/Gradio demos, notebooks.
- **Confidential work** rebuilt as a public demo or anonymised.
- **Habits as proof:** weekly charts, writing, talks.
- **Recruiter conveniences:** résumé download, stat tiles, location/work-authorisation answers, filters by tool.

## Required sections for the interview agent (Data Science)

1. Identity: name, title, level, city, remote/relocation.
2. Focus: experimentation, forecasting, NLP, recommendation, causal inference, product analytics, etc.
3. Projects (3 to 5): business question, data source and size, methods and why, metric and result (only if given), caveats, links (repo, notebook, demo), visuals.
4. Stack: Python, R, SQL, pandas, scikit-learn, PyTorch, Spark, cloud.
5. Experience, education, certifications.
6. Writing, talks, Kaggle, open source (optional).
7. Contact: email, WhatsApp, LinkedIn, GitHub, CV.
