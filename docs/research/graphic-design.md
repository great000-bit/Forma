## Patterns

- **Grids** dominate (covers, posters), but the strongest add one layer of meaning: a numbered index, a typeset table, a discipline filter.
- **Credits** matter: client, agency, team, printer, own role.
- **Commercial paths:** Hire, Commissions, Shop, Agent, Media kit.
- **Juniors** show a readable CV page and number their projects.
- **Personality** lives in the type and the navigation, not in extra sections.

## Required sections for the interview agent (Graphic Design)

1. Identity: name, title, city, studio name if any.
2. Disciplines: identity, editorial, packaging, posters, books, lettering, social, print.
3. Status: freelance, full-time, agency, commissions open.
4. Projects (6 to 12, more than other niches): client, discipline, year, your role, credits (agency, team), one-line concept, images (many), optional process.
5. Clients and awards (optional).
6. Shop or prints (optional link).
7. Experience or education.
8. Contact: email, WhatsApp, Instagram, Behance, agent (optional).

**Page sections:** hero, work grid (filterable), project pages (gallery + credits), about, clients, contact. **Niche-specific:** discipline filter, credits block, optional shop link, optional CV page.
